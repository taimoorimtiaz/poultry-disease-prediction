# poultry-disease-prediction
My Final Year Project is a Poultry Disease Prediction System. The main purpose of the project is to predict poultry diseases using an AI-based image classification model.

The user provides an image of a poultry bird or related symptom, and the trained AI model analyzes the image and predicts the possible disease. I developed the backend using Django, and the AI model is integrated with the backend to process the prediction.

The project helps poultry farmers identify possible diseases at an early stage and provides a faster way to support disease detection.
